# Ежедневник

Личный тёплый ежедневник для iPhone (PWA). Все записи и фото хранятся только на вашем устройстве.

## 1. Как запустить на своём компьютере

1. Установите Node.js: зайдите на https://nodejs.org и скачайте версию «LTS». Установите как обычную программу и перезагрузите компьютер.
2. Распакуйте архив. Получится папка `dnevnik`.
3. Откройте терминал:
   - Mac: программа «Терминал» (найдите через Spotlight).
   - Windows: «Командная строка» или PowerShell (найдите через «Пуск»).
4. Перейдите в папку. Напишите `cd ` (с пробелом на конце) и перетащите папку `dnevnik` в окно терминала, затем нажмите Enter.
5. Выполните `npm install` и нажмите Enter. Подождите 1–3 минуты, пока всё установится.
6. Выполните `npm run dev` и нажмите Enter.
7. Откройте в браузере адрес `http://localhost:5173`. Ежедневник работает.
8. Чтобы остановить: в терминале нажмите Ctrl + C.

Посмотреть на iPhone: компьютер и телефон должны быть в одной Wi-Fi сети. В терминале после запуска появится строка Network с адресом вида `http://192.168.1.5:5173`. Откройте этот адрес в Safari на iPhone.

Важно: установка на экран «Домой» и работа без интернета полностью проверяются только на настоящем сайте с https, то есть после публикации на Vercel (инструкция ниже).

## 2. Как опубликовать на Vercel (самый простой способ)

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Создайте новый репозиторий: нажмите «+» → «New repository», назовите его `dnevnik`, нажмите «Create repository».
3. Нажмите ссылку «uploading an existing file», перетащите внутрь всё содержимое папки `dnevnik` (папки `node_modules` и `dist`, если они есть, не загружайте) и нажмите «Commit changes».
4. Зайдите на https://vercel.com и выберите «Sign Up» → «Continue with GitHub».
5. Нажмите «Add New…» → «Project», найдите репозиторий `dnevnik` и нажмите «Import».
6. Ничего не меняйте (Vercel сам поймёт, что это Vite) и нажмите «Deploy». Через минуту появится адрес вида `https://dnevnik-xxxx.vercel.app`.
7. На iPhone откройте этот адрес в Safari, нажмите «Поделиться» → «На экран “Домой”». Дальше пользуйтесь ежедневником с иконки.

Обновления: когда у вас будет новая версия файлов, загрузите их в тот же репозиторий на GitHub (кнопка «Add file» → «Upload files»). Vercel сам опубликует новую версию, а ваши записи на телефоне останутся.

## Сохранность записей

Данные лежат только на телефоне. Регулярно нажимайте «Ещё» → «Сохранить и восстановить» и сохраняйте копию в «Файлы» или iCloud Drive. Не удаляйте иконку приложения с экрана «Домой», не сохранив копию: вместе с ней могут пропасть записи.
